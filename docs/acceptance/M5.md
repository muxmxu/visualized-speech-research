## 与 DESIGN 的偏差

首轮设置请求等待了频谱构建所持有的重计算信号量，在途缓存失效用例于 `release.wait(10)` 超时。A1 恢复了设置请求在构建中推进缓存代次的行为，并使较早代次的 analyzer 结果无法重新写入缓存。首轮失败日志和浏览器无障碍快照均已保留。Analyzer 的传输、时间原点和结果失效约定见 §21 D53。

## §17 性能

M5 无新增基准行。最近一组同平台实测来自 C1 候选 `fbb5061`，在 Raspberry Pi 5（Linux aarch64，CPU）上按 §17 顺序为 4.331 s、3.3837 s、63.0 ms、5.7 ms、558.9 ms、43.13 fps、165.124 ms，均为三次中位数。M4 与 M5 引用同一组实测，M5 无新增变化量。 [同平台实测记录](../dev/performance.md)
