## 与 DESIGN 不一致之处

本次版本更新没有引入产品差异。M4 的初始录音 idle、arm、Calibrate 与 WS 消息规则载于 D52。M5 的插件传输、时间原点、缓存失效和结果轨复用载于 D53。M5 首轮在途设置与浏览器控件定位问题已按 A1 定向复测。M4 三项真机检查为内置麦克风单轨、双硬件输入和物理回环加 overdub，结果仍待 Human 实测。WORLD Harvest 文档示例通过编译，执行该示例需装有可选 `pyworld` 的环境，本次未运行。 [真机步骤](../manual-checks.md) [插件文档](../plugins.md)
