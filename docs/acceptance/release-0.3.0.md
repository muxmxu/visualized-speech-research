## 候选构建与安装

在离线环境运行 `uv build`，wheel 为 739,938 字节，SHA-256 为 `cbea11727915a9143ac41accf7141d9a120b799d70db2ac10fc2a9907ab904f2`。检查确认 wheel 元数据版本为 0.3.0，45 个条目 CRC 正确，38 个受跟踪的 `src/vsr` 文件、三个生产 UI 资源和两个随包 skill 文件与候选输入一致。

新环境安装后，`vsr`、analyzer API、`dsp.rir_metrics` 均从该环境导入。带 token 的 `GET /api/session` 返回 200；不带 token 返回 401；主页返回 200，CSS 和 JS 资源也各返回 200。主页、CSS 与 JS 三个唯一 UI 内容的哈希均符合 M7 生产资源清单。`analysis` 的 48 kHz preset 可解析，随包 `presets.toml` 为 1351 字节。服务收到 SIGTERM 后停止，日志记录退出码 `-15`；shell EXIT trap 移除临时 venv 和运行目录。最终构建、wheel 检查、环境创建、依赖安装、wheel 安装、依赖检查与安装冒烟共八条命令的记录退出码均为 0。过程日志与 wheel 保存在忽略的 `agent_workspace/2026-11-16-autonomous-dev/tmp/C3-release-evidence/final2/`。

下列三次中位数在已通过审查的 M7 运行时代码树测得；候选源码与测试输入未变，故复用该证据。Raspberry Pi 5、Linux aarch64、CPU、Chromium 156.0.8078.79。与 0.2.0 候选 `8bf0403` 比较：
