# 真机检查

## M4 录音与多轨

启动 `uv run vsr serve`，打开它给出的地址。使用可丢弃的会话和测试音频，记录操作系统、设备、采样率、blocksize 与结果。

### 内置麦克风单轨

1. 允许系统访问麦克风。在 Record 选择内置麦克风，确认它是系统默认输入设备。采用设备默认采样率和 `FLOAT`，清除所有 arm 和 New Lane 映射，关闭 Overdub。
2. 将播放头移至所需起点，在传输栏按 Record，讲话几秒并观察增长的波形，再按 Stop。
3. 确认生成一条起点与播放头一致的单声道轨。播放并听辨刚才的语音，确认配置的录音目录中新建的 WAV 可打开。若出现录音警告，在通知和该轨 Properties 中核对类型及时间。

### 多通道声卡同时录音

1. 在 Record 选择至少有两个硬件输入的声卡，为前两个输入分别接入可辨识的信号，如两种不同节奏。用 New Lane 选中输入 1 与 2，为每路分别建单声道轨。
2. 轮流给两路输入送信号，核对顶部电平对应的通道及 clip 指示。然后同时送信号，录制几秒并停止。
3. 确认有两条同起点的新轨。分别 Solo 并播放，核对各轨的信号与输入编号，记下通知与 Properties 中出现的警告。

### 物理回环校准与 overdub

1. 选择同一声卡的输入与输出，将输出 1 接到输入 1。先降低输出和输入增益，并关闭声卡的直接监听，避免回授。
2. 在 Record 用所选采样率与 blocksize 执行 Calibrate。确认延迟补偿栏出现以 ms 为单位的测量值，记录该值，并确认会话未新增轨道。
3. 加载带有清晰脉冲的参考音频，保持参考轨可听并把播放头放到脉冲之前。用 New Lane 选择输入 1，打开 Overdub，保留测得的补偿值，开始录音，待脉冲经回环录入后停止。
4. 确认新轨起点等于录音开始时的播放头位置。放大对照参考及录得的脉冲，记录残余偏移和录音警告。

## M7 RIR 扬声器与麦克风测量

在安静房间使用可丢弃的会话。将一个输出通道接到扬声器，将麦克风接到输入通道；先降低硬件音量，并关闭会造成回授的直接监听。启动 `uv run vsr serve`，在 RIR 面板选择对应设备、通道和采样率。

1. 点击 Preview，确认扬声器以固定的 −30 dBFS 播放 1 秒扫频；检查没有意外的监听或过响。
2. 如需校准时间零点，在测量前选择同一设备上接有输出回环信号的输入通道作为 loopback；不接 loopback 时，结果应显示时间零点未校准。
3. 保持默认的单次测量参数，点击 Measure 播放并录下一次 ESS。使用低电平开始；高于 −6 dBFS 时，界面会要求单独确认。
4. 测量完成后，确认有效结果新增一条 RIR lane；打开系数–延迟图，检查直达声、后续到达的带符号读数及其延迟差。检查 EDC 与 C50/T20 数值。记录无效原因或 overflow / underflow 通知。
5. 在配置的 `recordings_dir/rir/<timestamp>/` 下找到此次测量子目录，确认 `raw_1.wav` 与 `rir.json` 可读取；有效测量还应有 `rir.wav`。检查元数据中的设备、采样率、测量参数和时间零点校准状态。
