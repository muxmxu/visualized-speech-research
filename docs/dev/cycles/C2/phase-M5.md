## Shared analyzer protocol

| Exchange | Wire and readback |
| --- | --- |
| `GET /api/analyzers` | JSON `{analyzers:[{id,label,version,input,params}], errors:[{file,error}]}`. `input` is `audio` or `feature`. `params` maps names to `{type,default,min,max,step,choices,unit,label}`, with `type` one of `float,int,bool,str` and unused fields null. Import failures remain visible in the list. |
| `POST /api/analyzers/{id}/run` | `{lane,t0?,t1?,channel?,params}`. Omit bounds for the whole lane or send both session-second bounds for the current selection. Audio sends the chosen zero-based channel or omits it for all channels. Params contains schema-typed values. Feature input uses its own frame centers and passes `frame_rate,freq_axis,value_scale` and source `sr`. |
| `TimeFreqImage` | JSON `{kind:"time_freq_image",lanes:[id],result:null}`. Session metadata is kind `feature` with parent, offset, rows, frames, frame rate, first frame time, axis and scale. Read with existing `/spectrogram`. |
| `TimeCurve` | JSON `{kind:"time_curve",lanes:[id],result:null}`. Session kind `curve` includes `parent,overlay,unit,y_scale,labels,curves,points,duration`. `GET /api/lanes/{id}/data` frames f32 named arrays `times:[T]` and `values:[K,T]`, with unit, y-scale and labels in the header. Normalize a single values row to `[1,T]`. Retain NaNs for line gaps. Render frequency overlays as chips and canvas lines on the parent plot. |
| `Events` | JSON `{kind:"events",lanes:[id],result:null}`. Session kind `events` includes parent and duration. `GET /api/lanes/{id}/data` returns `{items:[[t0,t1,label],...]}`. Draw labeled intervals in a lane. |
| `Spectrum` | Framed response with header `{kind:"spectrum",lanes:[],result:{unit,labels}}` and named f32 arrays `freqs:[F],values:[K,F]`. Frequency Analysis stores and plots the returned curves and unit. |
| `Scalars` | JSON `{kind:"scalars",lanes:[],result:{name:number,...}}`. Analyzers displays the values in its result table. |
| `Audio` | JSON `{kind:"audio",lanes:[id],result:null}`. Session kind `audio` includes parent and existing audio fields; waveform and playback use existing routes. |
| WS and errors | Emit existing `plugins_changed` on module-list or source mtime changes, including unchanged analyzer IDs and versions, and `lanes_changed` after a derived lane is committed. Re-list analyzers and refresh `/session` respectively. Run failures use §7's HTTP error body, with the real traceback available to expand in the notification. |

Audio slicing uses actual rounded lane-local sample bounds. Feature slicing uses center times and takes the first included center as the returned result's origin. Shift TimeCurve/Event times once to parent-local coordinates and use the parent's offset. Place derived images and audio at the actual input start on the session timeline. Retain IDs by parent and analyzer ID when rerunning lane results, advance version and clear stale. Follow §5 for stale state, offset propagation and cascading deletion. Apply these conventions through §21 decision D53. No new endpoint, option or runtime dependency is needed.
