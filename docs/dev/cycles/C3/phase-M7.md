## Bound contracts

| Interface | Binding |
| --- | --- |
| Analysis request | `POST /api/rir/analyze {lane,channel,bands,use_lundeby,truncation_s?}`. Channel is zero-based. Bands is null for all supported octave centers or a list of their Hz values. Broadband is always included. The optional cutoff is lane-local seconds. |
| Analysis result | JSON `{bands:{[band]:metrics},curves:{[band]:curve}}`, band key `broadband` or the octave center as a string. Metrics are `{T20,T30,EDT,C50,C80,D50,DRR,r2,noise_floor_db,crosspoint_s,reasons}`, with `r2` and `reasons` keyed by the relevant metric names and `onset_s,PNR` also on broadband. Unavailable or undefined values are null with a reason. Curve is `{times_s,envelope_db,edc_db,fits}`, with aligned lane-local times, null gaps, and `fits` keyed by `EDT,T20,T30` with two `[time_s,db]` endpoints or null. Cap the aligned points per band at the smaller of 4,000 and `floor(9000 / (3 * band_count))`, keeping the JSON within §6's small-result size. |
| DSP and plotting | Keep §16 signatures verbatim, `rir_metrics(h, sr, bands=None, use_lundeby=True) -> dict` and `rir(ax, h, sr, bands=None) -> dict`. Public calls take mono or the first channel of `[C,N]`; the server supplies the selected channel. Both use `vsr.dsp.rir.analyze_rir(h, sr, bands, use_lundeby, truncation_s=None)` for the same result schema. Static `rir` draws broadband EDC/fit and selected bands on the supplied axes and records the existing RIR spec line. |
| Measurement | `POST /api/rir/measure` takes `{input_device,output_device,sr,input_channels,output_channel,loopback_channel,f1_hz,f2_hz?,duration_s,amplitude_dbfs,fade_in_s,fade_out_s,pre_silence_s,tail_silence_s,repeats,ir_length_s,confirm_loud}`. Device null means system default, channels are zero-based, loopback null means absent. Apply §14.2 defaults including f2 based on sr, one repeat and a 1 s initial IR length control. Require `confirm_loud=true` above −6 dBFS. Return `{valid,reason,lanes,raw_paths,ir_path,metadata_path,time_zero_calibrated,loopback_delay_samples}`. Invalid takes retain raw data and metadata under the configured recording directory, with empty lanes and null IR path. A valid result adds one audio lane; its metadata includes `rir_time_zero_calibrated`. |
| Preview and arrival samples | `POST /api/rir/sweep_preview {output_device,output_channel,sr,f1_hz,f2_hz?}` plays the fixed 1 s, −30 dBFS sweep and returns `{ok:true}`. Arrival overview, raw zoom and single-sample reads reuse the approved arch-M7 `/lanes/{id}/waveform` framed path, with one selected channel, session-time bounds and original sample indices. |

Record these internal bindings in §21 D56 at integration. Preserve the accepted arch-M7 language, §19 and H45 capture scope.
