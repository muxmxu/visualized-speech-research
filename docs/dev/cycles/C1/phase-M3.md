## T1 — Edit, history and save in the existing backend

- Implement the §15 `edit`, `undo`, `redo` and `save` POST routes with the existing token, error and event paths. Convert session seconds to lane-local half-open sample bounds with `round((t - offset) * sr)`. Implement all §15 ops, keeping clipboard audio on the server and inserting paste at the playhead. Use the session lock, shared semaphore and selected float32 compute device for edit computation. Group one multi-lane edit into one history step. Keep whole-tensor per-lane snapshots under the separate `cache_bytes` budget, evict the oldest complete groups and clear redo when a new edit branches history. Publish changed versions, dirty state and derived stale flags through the existing lane metadata and event. Copy leaves history and version untouched. Extraction creates an aligned audio lane and is undoable without changing the source.
- Keep the M1 audition path on the same `spectral_mask`. Attenuate with `1 + (gain - 1) * mask`; use the source view's FFT and window with `win_length // 4` hop. Apply the §15 replacement interval and `n_fft`-sample crossfades with exact passthrough outside the interval. Extract with the same mask. Only edits to the T-F owner lane and channel apply to a rectangle.
- Save only WAV or FLAC and honor the requested subtype. Resolve the original and explicit target paths before deciding whether a write is replacing the source. Require a unique ordinary WAV/FLAC lane for writeback. Unsupported source types and shared-source lanes return 400 for implicit save. Keep input files untouched during editing and keep dataset directories read-only. Write via a same-directory temporary file and `os.replace`, clean up the temporary file on failure, preserve existing destination bytes and clear dirty only on successful save.
- Internal conventions for T1 and T2 use the existing edit payload. A spectral delete passes `params.gain_db = "-inf"` because JSON has no numeric infinity. A grouped time edit lists the extra selected lane IDs in `params.lane_ids` and commits as one edit. The §9.6 time-only Extract uses the existing `spectral_extract` dispatch with only the time bounds and takes the exact time slice through the same lane-creation and history path. T-F extract continues to supply the complete §15 spectral parameters. Record these bindings in DESIGN §21 during T3.

Focused check: `uv run pytest tests/test_edit.py tests/test_save.py`. Use code-generated signals and parameterized rows for the operation and save criteria below. Cover grouped undo/redo and extraction undo in the history cases. Validate PCM_24 against one 24-bit quantization step (2⁻²³) and FLOAT against the source float32 samples.
