## Mask phase decision for §15

On each axis with inclusive rectangle edges `[l,r]` and step `s`, use exterior distance `d = max(l-x, 0, x-r)`. Define the axis weight as 1 for `d=0`, `(1 + cos(pi*d/(2*s)))/2` for `0<d<2*s`, and exactly 0 for `d>=2*s`. Multiply the time and frequency axis weights. The time step is `H/S` for `H=win_length//4` and the frequency step is `S/F` for `F=n_fft`. This preserves full gain inside the rectangle, including its edges, and gives each exterior transition the §15 two-frame or two-bin width even when the edge falls between grid points. Both transitions start at the actual rectangle edges. Their product defines the corners.

This records the minimal §15 implementation decision for the Controller to number in `docs/dev/decisions.md` and assign to T8 for a §21 entry under D34. The basis is §15's in-rectangle specified gain and §7's zero beyond the transition. A later approved phase convention can replace this edge profile and its dedicated numeric fixture. Use one membership function in `dsp/edit.py` for audition and later M3 callers, so M3 can apply `1 + (target_gain - 1)*weight` for attenuation and reuse the weights for extraction. Keep M3 wiring outside T3.

Evaluate centers as absolute frame index `k` times `H/S` and bins as absolute index `j` times `S/F`. Compute transition positions without losing the sub-frame offset to float32 rounding of large absolute times, for example by splitting each edge into its integer grid cell and fractional position and evaluating short differences near it. Keep the transform, synthesis and float32 mask coefficients on the selected compute device. The T2 `stft_chunk` already shows the correct absolute addressing but returns calibrated dB, so use the shared periodic window directly and retain complex coefficients for masking.

## Bounded source and analysis support

The following are half-open bounds on absolute, lane-relative sample and frame grids.

1. For unequal rates reduce by `gcd(R,S)` to `U=R/gcd(R,S)` and `D=S/gcd(R,S)`. Preserve the route's default `resample_poly` zero extension and conservative source margin `M=ceil(10*max(U,D)/U)+2`. The default SciPy FIR half-length is `10*max(U,D)` on the upsampled grid. Its centered output sample `m` depends only on source indices `n` with `abs(m*D-n*U) <= 10*max(U,D)`. The margin covers the entire two-sided FIR support and sample rounding.
2. Use `A = max(0, ((floor(a*D/U)-M)//D)*D)` and `B = min(N, ceil(b*D/U)+M)`. Use integer ceil/floor for index arithmetic. The start aligns to a multiple of `D`, so `O=A*U//D` is an integer destination index and the local resample has the full-lane phase. Reconstruct masked source samples `[A,B)` first, then resample that interval along the sample axis and return `[a-O,b-O)`. At physical sample 0 and `N`, SciPy zero extension supplies support beyond the lane. The same-rate branch needs neither FIR margin nor resampling.
3. To reconstruct `[A,B)` with `F=n_fft`, `q=F//2` and `H=win_length//4`, the whole-lane centered transform has `K = 1 + (N + 2*q - F)//H` frames for nonempty `N`, and absolute frame `k` covers `[k*H-q,k*H-q+F)`. Retain all available frames whose support intersects `[A,B)`. This gives `k0=max(0,(A+q-F)//H+1)` and `k1=min(K,(B-1+q)//H+1)`. Including frames with zero mask weight still contributes their window squared to the ISTFT denominator.
4. Analyze the slice `[k0*H-q,(k1-1)*H-q+F)` after clipping the source read to `[0,N)` and padding only the physical lane overhang with zeros. A `center=False` STFT on this explicit padded read reproduces the `center=True, pad_mode='constant'` whole-lane frames. This accounts for both sides of the analysis window, including Torch's centered zero padding when `win_length<F` and the odd FFT asymmetric support. Never zero-pad at an internal PCM seam.
5. Apply the mask at the absolute frame and bin coordinates. Synthesize using the matched periodic window and hop, with normal ISTFT squared-window normalization. A centered ISTFT of the retained coefficients starts at absolute sample `k0*H`. Explicitly use `length=B-k0*H` and cut off the leading `A-k0*H` samples. This covers the synthesis overlap of every sample in `[A,B)`, even where the centered inverse runs past the last retained frame center. The equivalent direct overlap-add is valid with the same numerator, window-squared envelope and crop. Retain only the requested range plus its FIR and analysis margins for production, including when the rectangle covers the rest of the lane.
