App currently has only time and move tools (`frontend/src/App.tsx:102`), one time selection, and one row per lane (`:181`); it has no WebGL renderer, per-view spectral state, Display or Frequency Analysis panels.
- Playback schedules aligned 20-second chunks (`frontend/src/audio/playback.ts:6`, `:79`) and builds PCM queries at `:92`; T-F audition needs the selected lane and originating view parameters carried into this path. Existing selection UI and playback behavior must remain interoperable with the independent T-F selection.
- `src/vsr/skills/vsr-speech-visualization/presets.toml:1` is the human-owned source, including analysis, wideband and narrowband (`:6`, `:19`, `:32`); conversion and spec-line contracts are `docs/DESIGN.md:531`. The TOML is not to be modified.

## M1 contracts and dependencies

- STFT calibration and windows are specified at `docs/DESIGN.md:220`; cache key, chunking, half-precision cache, max pyramids, absolute grid, log bin interpolation and response metadata are specified at `:235`. Implementations must use the selected compute device and framed transport; requests coalescing and memory limits are explicit acceptance items (`:653`).
- Frequency analysis has distinct frame, Welch and full methods, units and active-frame behavior (`docs/DESIGN.md:252`, `:276`); T-F limits display only (`:259`). Public API signatures are fixed at `:557`. The mask and its 2-frame / 2-bin edge transitions and crossfade are specified at `:521`; PCM chunk boundaries require the same masked result as whole-lane processing (`:206`, `:655`).
- One WebGL2 context spans lanes with per-view scissor; axes, waveform and interaction overlays remain separate (`docs/DESIGN.md:326`). Request scheduling, shader-only display changes and f16 hover decoding are specified at `:329`; multi-view state must isolate FFT settings (`:297`). The renderer depends on the viewport response and metadata contract; T-F interaction and frequency zoom depend on correct coordinate mapping. Frequency panel and audition depend on spectral DSP and selection state, respectively.
- M1's numerical, request-count, independent-view, memory, concurrency and chunk-continuity checks are listed at `docs/DESIGN.md:642`. Performance rows 2–6 are measured rather than pass thresholds (`docs/DESIGN.md:580`).
- H45 / D40 requires a distinct screenshot selection, composition of the current rendered layers and a downloaded one-page raster PDF, with no DSP recalculation, backend route, audio write or runtime dependency (`docs/dev/decisions.md:29`). The existing waveform, selection and playhead are separate canvas and DOM layers (`frontend/src/App.tsx:69`), so faithful composition must account for all visible layers, clipping, scroll and device-pixel scaling. A browser canvas can provide raster bytes and browser Blob/download APIs can deliver a PDF; a small correctly structured PDF wrapper is feasible without a library, but faithful WebGL and DOM composition and PDF-reader compatibility remain unverified. D40 requires design consultation if faithful composition cannot be achieved; it is not a license to substitute static plotting. The required plan amendment and architecture delta precede implementation.

## Headless browser preflight

- With the existing Playwright dependency and the host-selected Chromium 156 in headless mode, `canvas.getContext('webgl2')` returned a context. This checks context creation only, not the M1 renderer, hardware acceleration or WebGL layer capture.
- A 64 × 32 Canvas2D image encoded through `toBlob('image/jpeg', 0.95)` produced an `image/jpeg` Blob of 784 bytes. Browser-native typed arrays and Blob construction produced a 1,454-byte PDF 1.4 containing that JPEG; an anchor with an object URL triggered a Playwright download with no reported failure.
- The installed `pdfinfo` recognized one page of 64 × 32 points; `pdftoppm` rendered it as a 64 × 32 RGB PNG at 72 dpi. This establishes a minimal no-added-dependency PDF and download path in this environment, not fidelity of composed application layers, color verification, or compatibility across PDF readers. Temporary artifacts were removed.
